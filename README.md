# Toki Mohammad Tahmid - CV Website

Minimal one-page CV site: civil engineer in QA/QC and technical documentation, with self-taught IT work. Plain HTML, CSS and JavaScript, no build step.

Live: https://tamidtoki.github.io/CV_Website/

## Structure

```
index.html
css/styles.css
js/main.js
assets/Toki_Mohamamd_Tahmid_CV.pdf
assets/favicon.svg
```

## Run locally

```bash
python -m http.server 8000
```

Open http://localhost:8000.

## Deploy

GitHub Pages: Settings > Pages > Deploy from a branch > `main` / root.
